# Руководство пользователя Telegram-бота

**STAL Analogs Manager** — Telegram-бот для работы с базой соответствий `STAL-артикул → аналоги`. Все операции выполняются через backend API (`stal-analogs-storage`); бот принимает текст и файлы, показывает предпросмотр и сохраняет данные только после вашего подтверждения.

---

## Быстрый старт

1. Откройте бота и отправьте `/start`.
2. Напишите задачу обычным текстом или прикрепите файл с подписью.
3. Дождитесь ответа. Для долгих операций (файлы, извлечение) бот сначала напишет «Думаю...», затем пришлёт результат.

### Команды


| Команда  | Действие                                                   |
| -------- | ---------------------------------------------------------- |
| `/start` | Перезапуск, приветствие                                    |
| `/help`  | Обучалка с разделами (поиск, файлы, глубокий поиск и т.д.) |
| `/new`   | Новый диалог: сброс контекста и активного предпросмотра    |


### Контекст диалога

Бот помнит последние сообщения и прикреплённый файл. Если **30 минут** не было сообщений, сессия сбрасывается автоматически. Команда `/new` очищает контекст вручную.

> Доступ ограничен whitelist Telegram user_id. Если бот отвечает «У вас нет доступа», обратитесь к администратору.

---

## Как писать боту

Бот передаёт ваше сообщение в AI-агент на backend. Агент выбирает действие и выполняет его. Формулировки могут быть свободными — главное, чтобы из текста было понятно намерение.

### Общие правила

- **Указывайте артикулы явно** — бот не придумывает коды, которых нет в сообщении или файле.
- **STAL-артикулы** выглядят как `ST` + цифры, например `ST20868`, `ST11013`.
- **Аналоги** — любые другие артикулы (Donaldson, Fleetguard, Baldwin, OEM и т.д.).
- **Файл + текст:** прикрепите документ или фото и напишите в подписи (или отдельным сообщением сразу после), что сделать.
- **Только файл без текста:** бот попросит уточнить — извлечь связки или сделать глубокий поиск.

### Примеры формулировок

```
Добавь к ST20868 аналоги P551039 и P550690
Найди ST11013
Что подходит к AT112393?
Удали ST20868
У ST11013 убери аналоги A123 и B456
Покажи аналоги для ST20868
```

## Извлечение артикулов из файлов

Главная задача бота — не вбивать сотни соответствий вручную, а **загрузить прайс, таблицу перекрёстных ссылок, PDF или скан** и получить готовый список связок `STAL → аналоги`.

### Поддерживаемые форматы


| Формат                              | Как обрабатывается                                                     |
| ----------------------------------- | ---------------------------------------------------------------------- |
| `xlsx`, `xls`, `csv`                | Таблица преобразуется в текст по строкам, затем AI извлекает артикулы  |
| `pdf`, `png`, `jpg`, `jpeg`, `webp` | Файл отправляется в AI для распознавания таблиц и кодов на изображении |


Отправляйте файл **как документ** (для Excel/CSV надёжнее). Фото тоже принимается.

### Два режима работы с файлом

#### 1. Обычное извлечение (прямые связки)

AI ищет в файле группы артикулов одного товара и определяет, какой из них — **STAL** (`ST` + цифры). Остальные коды в группе становятся аналогами.

**Когда использовать:** в файле есть колонки или строки с кодами STAL и рядом — аналоги.

**Примеры сообщений с файлом:**

```
Вытащи отсюда артикулы
Найди STAL и аналоги в этом прайсе
Обработай файл и покажи что нашёл
Импортируй соответствия из вложения
```

#### 2. Глубокий поиск (косвенные связи)

В файле **может не быть STAL-кодов**. AI извлекает **строки/группы артикулов** (все коды в одной строке = один товар). Backend сравнивает каждый код с уже сохранённой базой в Google Sheets:

- колонка **A** — STAL-артикулы;
- колонки **B–Z** — известные аналоги.

Если **любой** артикул из новой строки уже есть в базе (как STAL или как аналог), вся строка из файла предлагается к добавлению к найденному STAL.

**Когда использовать:** новый прайс поставщика без колонки STAL, но с артикулами, которые уже есть в вашей базе.

**Примеры:**

```
Сделай глубокий поиск по этому файлу
Найди совпадения через уже сохранённые аналоги
Сопоставь строки файла с нашей таблицей
```

### Схема работы с файлом

```text
Вы отправляете файл + команду
        │
        ▼
AI извлекает артикулы (с учётом ваших инструкций)
        │
        ▼
Бот показывает ПРЕДПРОСМОТР (ничего не сохраняется)
        │
        ├── «применить» / «сохранить» / «да»  →  запись в Google Sheets
        ├── «отменить» / «нет»                 →  отмена без сохранения
        └── текст с правкой                    →  обновлённый предпросмотр
```

**Важно:** данные попадают в базу **только после вашего подтверждения**.

### Предпросмотр

После извлечения бот присылает:

- краткий список связок в чате (первые 20 записей);
- если записей больше 20 — дополнительно **XLSX** с полным списком (`*_preview.xlsx`).

Дальше ответьте текстом:


| Ваш ответ                             | Что произойдёт                                                     |
| ------------------------------------- | ------------------------------------------------------------------ |
| `применить`, `сохранить`, `да`, `ok`  | Данные записываются в Google Sheets                                |
| `отменить`, `отмена`, `нет`, `cancel` | Предпросмотр сбрасывается, в базу ничего не пишется                |
| Любая правка (см. ниже)               | AI пересобирает предпросмотр; снова нужно подтвердить или отменить |


### Инструкции: как именно извлекать данные

Вы можете **уточнить в сообщении**, как читать файл. Агент передаёт эти указания в AI при извлечении. Они дополняют стандартные правила, но не отменяют их (например, STAL по-прежнему должен быть в формате `ST` + цифры).

**Что можно указать:**

- из **какой колонки** брать STAL-артикул;
- из **каких колонок** брать аналоги;
- **какой лист** Excel обрабатывать;
- с **какой строки** начинать (пропустить шапку);
- что **игнорировать** (пустые строки, служебные колонки, цены, наименования);
- как **группировать** коды в одной строке;
- разделители, если структура нестандартная.

**Примеры сообщений с инструкциями:**

```
Обработай файл. STAL в колонке A, аналоги в колонках C, D и E. Первую строку пропусти.
```

```
Извлеки артикулы: STAL — столбец «Код STAL», аналоги — «Donaldson» и «Fleetguard». Лист «Прайс».
```

```
Глубокий поиск. Каждая строка — один товар. Артикулы в колонках B–G. Колонку с ценой не трогай.
```

```
В этом PDF таблица: слева STAL, справа через запятую аналоги. Возьми только строки, где STAL начинается с ST.
```

```
Убери дубликаты и строки без STAL-кода
```

Инструкции можно давать **вместе с файлом** (в подписи) или **отдельным сообщением** сразу после отправки файла — бот помнит последний прикреплённый файл в сессии.

### Правка предпросмотра

Если после извлечения что-то не так, опишите правку обычным текстом — перезагружать файл не обязательно:

```
Убери ST99999 — это ошибка распознавания
Удали дубликаты аналогов
Оставь только строки, где больше двух аналогов
Для ST20868 замени аналоги на P551039, P550690
Исключи артикулы из колонки «Снято с производства»
```

После правки снова проверьте список и напишите `применить` или `отменить`.

### Если ничего не нашлось

При обычном извлечении бот сообщит, что в файле нет подходящих таблиц с артикулами (или нет строк с кодами STAL). Типичные причины:

- файл — не прайс и не таблица перекрёстных ссылок;
- STAL записан в нестандартном виде (не `ST` + цифры);
- нужны **инструкции по колонкам** — попробуйте уточнить структуру;
- для файла **без STAL** используйте **глубокий поиск**, если в базе уже есть пересекающиеся артикулы.

## Как устроена база

В Google Sheets каждая строка — один STAL-артикул:


| Колонка         | Содержимое                                 |
| --------------- | ------------------------------------------ |
| **A**           | STAL-артикул                               |
| **B–Z**         | Аналоги                                    |
| *(notes ячеек)* | Служебно: источник файла, время обновления |


При массовой загрузке из файла новые аналоги **добавляются** к уже существующим (не затирают всю строку), если вы явно не просите заменить список целиком.

## Частые вопросы

**Бот долго не отвечает после файла**  
Извлечение и глубокий поиск — долгие операции (до нескольких минут). Дождитесь ответа; не отправляйте тот же файл повторно, пока не пришёл результат или ошибка.

**Можно ли отправить файл, а команду — следующим сообщением?**  
Да, в рамках одной сессии бот использует последний прикреплённый файл.

**Нужно ли каждый раз заново загружать файл для правки предпросмотра?**  
Нет. После извлечения правки делаются текстом; файл уже не нужен.

**Файл не принимается**  
Проверьте расширение: `xlsx`, `xls`, `csv`, `pdf`, `png`, `jpg`, `jpeg`, `webp`. Файл не должен быть пустым.

**Бот не подключается к API**  
Убедитесь, что backend запущен и в `.env` бота указан правильный `API_BASE_URL`.
